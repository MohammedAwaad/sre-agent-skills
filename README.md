# sre-agent-skills

Agent skills for everyday SRE work, written once and usable in both **Claude Code** and **OpenAI Codex**.

Both tools support the open [Agent Skills](https://agentskills.io) format: a folder with a `SKILL.md` file whose front matter (`name`, `description`) tells the agent when to use it. The agent loads the full instructions only when a task matches, so installing several skills costs little context.

## Skills

| Skill | What it does |
|---|---|
| [postmortem-from-timeline](skills/postmortem-from-timeline/SKILL.md) | Turns a chat log or timeline notes into a blameless postmortem draft with durations, contributing factors and owned action items |
| [runbook-to-script](skills/runbook-to-script/SKILL.md) | Converts a manual runbook into a Bash or Python script with dry run by default, read only checks first and confirmation before every change |
| [log-triage](skills/log-triage/SKILL.md) | Groups log lines into patterns, finds what started at the incident start, and ranks leads with evidence and the next command to run |
| [incident-status-update](skills/incident-status-update/SKILL.md) | Writes consistent internal or customer facing status updates from the current incident state |

## Install

```bash
git clone https://github.com/MohammedAwaad/sre-agent-skills.git
cd sre-agent-skills
./install.sh            # both tools, for your user
./install.sh claude     # Claude Code only
./install.sh codex      # Codex only
./install.sh --project  # into the repository you are standing in, for the whole team
```

Where the skills go:

| Tool | User level | Project level |
|---|---|---|
| Claude Code | `~/.claude/skills/<skill>/SKILL.md` | `.claude/skills/<skill>/SKILL.md` |
| OpenAI Codex | `~/.agents/skills/<skill>/SKILL.md` | `.agents/skills/<skill>/SKILL.md` |

Or copy the folders by hand; there is nothing else to install.

## Use

The agents pick a skill automatically when your request matches its description, for example:

* "Here is the incident channel export, draft the postmortem."
* "Turn this runbook into a script."
* "These are the logs from 14:00 to 14:30, what changed?"
* "Write a customer status update: payments failing for about 20% of users, fix being deployed."

You can also call one directly: in Claude Code type `/postmortem-from-timeline`; in Codex type `$postmortem-from-timeline` or pick it from `/skills`.

## Design principles

* **Drafts, not decisions.** Every skill produces something a human reviews. Nothing is sent, deployed or changed by the skill itself.
* **No invented facts.** Missing information becomes `TODO: confirm`, never a guess.
* **Safe by default.** Scripts generated by `runbook-to-script` run in dry run mode unless told otherwise.
* **Keep secrets out.** Skills point out and mask tokens and personal data found in the input.

Pairs with [sre-runbook-kit](https://github.com/MohammedAwaad/sre-runbook-kit) (the templates these skills follow) and [linux-triage](https://github.com/MohammedAwaad/linux-triage).
